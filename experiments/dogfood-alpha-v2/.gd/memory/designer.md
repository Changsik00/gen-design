## 작업 패턴

- 영어 용어 만나면 *바로 물어봄* ("그게 뭐예요?")
- 결과가 화면에 안 보이면 *멈춤* ("결과는 어디서 봐요?")
- 명령 두 번 실행 안 함 — 한 번에 안 되면 *멈춤*
- 자기 답이 맞는지 확신 없을 때: "이렇게 하면 되나요?"
