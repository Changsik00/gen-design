### Tier 1 (ARIA) 처리

ARIA 1.3 의 80+ role + state 는 *정적 enum*. WAI-ARIA spec 의 role 이름 + 부모 (abstract role) + 필수 속성을 JSON 으로 박아 둠 (W3C 페이지 변경 빈도 낮음).

### spec.md JSON Schema 생성

카탈로그 JSON → JSON Schema. 핵심:
- 컴포넌트 enum (등록된 이름만)
- 각 컴포넌트의 axis 별 value enum
- `tokens` prop 의 값은 *토큰 참조 패턴* 만 (`{{token.xxx}}`)
- raw hex/rgb/hsl 거부 패턴
- `theme` attribute enum (등록된 theme 만)
- ARIA role override 패턴
